# AI Recommendation System

## Overview
The AI Recommendation System is a simple Python project that recommends items based on the user's interests. It uses basic AI recommendation logic by matching user preferences with predefined categories and displaying the most relevant results.

## Features
- Takes user preferences as input.
- Matches interests with predefined categories.
- Calculates a similarity score.
- Displays personalized recommendations.
- Beginner-friendly Python project.

## Technologies Used
- Python 3

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the Python file:
   ```
   python recommendation.py
   ```
5. Enter your interests when prompted.
6. View the recommended items.

## Example

**Input:**
```
technology, python, gaming
```

**Output:**
```
Recommended Items:
Python Programming
Machine Learning
Gaming
```
